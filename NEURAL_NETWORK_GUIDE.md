# MMC Liquidity Hunt Predictor — How to Use

## Set Your Bias First
Top-down from D1 or H4 — which direction is the market going?

## Then Toggle What You See on the Chart

- `FVG at boundary` — there's a Fair Value Gap at the edge of the context area → FLOD fires
- `ODD zone` — FVA and FVG are overlapping → strongest usual setup
- `FVA rejection failing` — price entered the FVA but isn't bouncing → something is wrong with the narrative
- `Opposing FVG` — with failing + opposing FVG → unusual context, LOD is now exposed
- `ITH above / ITL below` — mark whether the liquidity level actually exists in your direction

## The Network Then

1. Classifies the context (FLOD / ODD / Unusual)
2. Reads the narrative (usual vs unusual)
3. Either follows your bias (usual) or **reverses it** (unusual)
4. Predicts which liquidity gets hunted with a confidence score

## Key Insight

The unusual context path is the most powerful — when it fires and says Hunt ITL while you had a bullish bias, that's the market trapping late buyers and going for the lows. That's S5, highest conviction, 63% win rate on GBPUSD.

| Setup | Confidence | Why |

| FLOD | 65% | First line of defense — can still fail |
| ODD | 78% | Double confirmation (FVA + FVG overlap) |
| Unusual Context | 88% | LOD is fully exposed, market has no defense left |
