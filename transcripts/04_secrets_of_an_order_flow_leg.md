## Summary
- **Direction** = which PD array to trade *towards*. **Narrative** = which PD array to trade *from* (how we deliver to the target).
- An order flow lag holds all three PD arrays → three things to potentially trade from. But each has a different **probability**. Trading is about probabilities — always take the highest-probability scenario.
- Find order flow lags starting from the **monthly → weekly → daily** (highest timeframe = strongest). Stop drilling down as soon as you find an order flow lag. A lower-TF FVG sitting *inside* a higher-TF FVG is **not in context** (weaker).
- **Why higher TFs matter:** institutions execute on 4H/daily/weekly/monthly, not 1m/15m.
- **Dissecting the lag — FLOD / ODD / LOD:**
  - **FLOD (First Line of Defense):** first PD array price retraces into. Best = **fair value gap** (more bearish/bullish intention). Worse = fair value area is the FLOD.
  - **ODD (Overlapping Defense, a.k.a. O-LOD):** first area where two PD arrays overlap. Best = **fair value area** overlapping with the FVG (two discount/premium arrays = double probability).
  - **LOD (Last Line of Defense):** always the **swing point**.
    - Best LOD = a lag with **no FVG** (the swing point is the only thing to trade *from* — a sweep/respect to continue).
    - If the lag **has an FVG** (normal order flow lag), the LOD is something to trade **towards**, not from — because if the fair value area stops offering fair value, the market is seeking liquidity, and that liquidity is the swing point. This is **unusual context**.
- **Market is always doing one of two things:** offering fair value OR seeking liquidity.
- **Case study:** study FLOD, ODD, LOD on your chart — see where they hold and where they don't.
