## The MMC framework (how the videos build on each other)
1. **Direction** (videos 1–3, 5): *Price is always moving towards a PD array* — find which one is next using FVGs, swing points, market structure (ITH/ITL, STH/STL), order flow lags, and candle science.
2. **Narrative** (videos 4, 6, 7, 8): how price *delivers* to the target — the order flow lag broken into **FLOD** (FVG), **ODD** (FVA), **LOD** (swing point), plus FVG/FVA quality and liquidity sweeps.
3. **Time** (video 9): volatility / news events — does the PD array have the energy to hold?
4. **Context** (video 10): the objective area (boundary → first opposing PD array) where you look for entries; usual vs unusual context.
5. **Entry** (video 11): sharp turns & order flow entries inside context (a context area = a market maker model).
6. **Top-down** (video 12): tie it all together; pick filtering-process vs flow-trader style.

**Recurring core idea:** the market is always either **offering fair value** or **seeking liquidity** — and **fair value gaps are superior** (no FVG → no order flow lag → no fair value area).
